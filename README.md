# Public app website

This repository contains the main public site (`index.html`) and the root-level `app-ads.txt` used for advertising verification. Keep `app-ads.txt` at the site root.

Privacy policies are maintained in [app-privacy](https://github.com/steveazul87/app-privacy). Until its site is published and existing links are migrated, the homepage links to the currently published privacy and support pages.

GitHub Actions is disabled, so changes to this repository will not be deployed through GitHub Pages until publishing is restored.
